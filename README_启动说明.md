# 启动说明 · 无人机数据集生成平台（v7.7 · 自定义航线版）

> 本说明供团队同伴在本机运行本项目，并演示本次新增的"自定义航线"功能。

---

## 1. 运行环境要求（首次准备）

- **Node.js + npm**（跑界面用）
- **Anaconda / Miniconda**，并创建一个装有以下包的 Python 环境（README 里建议环境名 `carlaAir`）：
  - `carla`（从 Carla-Air 的 `PythonAPI/carla/dist/*.whl` 安装）
  - `airsim`（`pip install airsim`）
  - `flask`、`flask-cors`、`numpy`、`Pillow`
- **Carla-Air 仿真器**（30GB，目录内需有 `StartCarlaAir.bat`）

---

## 2. 启动步骤

### 桌面快捷方式（最省事）

安装好后桌面上会有两个快捷方式，双击即可：

| 快捷方式 | 作用 |
| --- | --- |
| **启动 Carla-Air 仿真器** | 一键拉起 CarlaUE4（地图默认 Town10HD） |
| **启动 无人机数据集平台** | 一键拉起后端 + 平台界面 |

两个**不分先后**：谁先起都行。仿真器如果在平台之后才起来，后端会自动附着上去（后台每 4 秒探测一次 2000 端口），**不用再回界面点任何按钮**。

> 快捷方式由 `启动仿真器.bat` / `启动平台.bat` 创建。换电脑/重新 clone 后，可手动右键 `启动仿真器.bat` → 发送到 → 桌面快捷方式。

### 方式 A（推荐）：双击 `启动平台.bat`

在项目根目录双击 **`启动平台.bat`** 就行，脚本会自动：

1. 检查 Node.js / 前端依赖（缺依赖会自动 `npm install`）
2. 自动寻找可用的 Python 环境（优先带 `carla`+`airsim` 的 `carlaAir`，其次项目 `.venv`，再次 PATH 上的 python）
3. 缺 `flask` 时自动 `pip install flask flask-cors`
4. 起后端（会弹出一个 **"平台后端"** 窗口，别关它）；已在运行则直接复用
5. 打开界面窗口

看到 `[OK] 后端就绪` + `[..] 打开界面` 就是成功了。

> 只想检查环境、不启动：命令行执行 `启动平台.bat check`

### 方式 A2：双击 `启动仿真器.bat`（只起仿真器）

- 地图优先级：**命令行参数** > 上次用过的地图（记在 `.carla_last_map`）> `Town10HD`
  - 例如 `启动仿真器.bat Town03`
- Carla-Air 路径来源：应用配置里的 "Carla-Air 文件夹路径" > `D:\Carla-Air`
- 已经在运行时**不会重复启动**（会提示并退出），换地图请先跑 `D:\Carla-Air\StopCarlaAir.bat`
- 会等 **CARLA 2000 + AirSim 41451 两个端口**都就绪才报成功（首次加载约 20-60 秒）

**几个提醒**

- 启动日志里如果出现 `手动配置未完成，等待用户配置` / `后端启动失败，等待用户手动配置`，这是 **Electron 在说"我没自己拉后端"**（因为它还没读到 Carla-Air 路径配置）。后端正由脚本启动着，**不影响使用**；要采集/巡航时再去"🚀 仿真器配置"页填路径即可。
- 界面关掉后，后端还留在那个"平台后端"窗口里。下次双击脚本会自动复用它；想换 Python 环境，先把那个窗口关掉再重启脚本。
- 已用"只能预览"的环境起过后端、又想换成 Carla-Air 环境时，同样要先关掉"平台后端"窗口。
- 如果你自己在外面启动了 Carla-Air（或它还开着），在「🚀 仿真器配置」页点 **「🔗 连接已有仿真器」** 就能附着上去，**不会重启仿真器**。

### 方式 B：两个终端手动起

**终端 1 —— 启动后端：**
```powershell
conda activate carlaAir
cd <本项目目录>
python backend.py
```
看到 `API 服务器启动: http://localhost:5000` 即成功。

**终端 2 —— 启动界面：**
```powershell
cd <本项目目录>
npm install      # 首次运行需要（装 Electron 依赖）
npm start        # 打开 Electron 窗口
```

> 没有 Carla-Air / 缺 carla、airsim 时，后端仍可启动（预览功能可用，采集/规划接口会给出明确提示）。

### 用浏览器打开（可选，功能受限）

界面是 Electron 桌面应用。真要当网页看，必须用 http 服务（**直接双击 `index.html` 不行**，浏览器会按 CORS 规则拦掉 ES 模块，页面是死的）：

```powershell
cd <本项目目录>
python -m http.server 8123 --bind 127.0.0.1
```
然后浏览器打开 `http://127.0.0.1:8123/index.html`。

功能上会缺：启动/停止 Carla-Air、选文件夹/解释器/settings.json 的对话框、数据集 JSON+CSV 落盘（这些依赖 Electron 主进程）。地图预览、路线规划、巡航按钮仍可用。

## 3. 演示"自定义航线 + 自动巡航"功能（地图与路线页）

1. 左侧导航进入 **"地图与路线"**
2. 点 **"读取地图"**（Town10HD 有内置拓扑缓存，无 CARLA 也能看到路网 + 橙色固定航线）
   - **滚轮缩放**（以光标为不动点）、**按住左键拖动平移**、**"重置视图"** 回到自适应视图
   - 光标移动时右下角实时显示所在位置的 CARLA 坐标，方便对准位置
   - 拖动结束后不会误加航点（拖动与点选已区分）
3. 在地图上依次点击 **起点 / 途经点 / 终点**（≥2 个点）→ 出现**绿色规划线**
   - ⚠️ 生成绿色规划线需要 **CARLA 仿真器运行**（吸附 + 最短路径要读实时路网）
   - 选点精度：v2 先把点击点投影到最近车道中心线，再在道路图上找最近的**边**并把锚点插进去，
     所以起/终点落在你点的那条路上，而不再是"最近的路口节点"（旧实现误差可达数米）
4. 点 **"💾 保存自定义路线"** → 航线保存到 `recordings/drone_routes/custom/`，并自动切到"自定义路线"模式
5. **"固定航线 / 自定义路线"** 模式开关可随时切换本次巡航执行哪条航线
6. 在 **"自动巡航"** 面板设置高度/速度，点 **"✈️ 开始自动巡航"**：
   - 自动确认 CARLA 就绪 + 地图一致（不一致会自动切换）
   - 一键连接 AirSim、起飞、沿所选航线巡航（后端只调用一次 `moveOnPathAsync`）
   - **⏸️ 暂停** 停止巡航并悬停；**🛬 降落** 原地着陆
   - 右侧"任务状态"实时显示巡航状态、无人机位置、路径进度（`n / 总航点`）
7. 在 **"采集控制"** 页点 **"🚁 生成数据集"**：若当前为"自定义路线"模式且航线与所选地图一致，采集会自动沿该自定义航线飞行（`route_id` 已接入采集流程）

| `启动平台.bat` / `启动仿真器.bat`（新增） | 一键启动脚本（自动找 Python/依赖、自动等端口），桌面快捷方式指向它们 |
| `main.js` / `simulator.js` | 后端握手改用 `127.0.0.1`（避免 `localhost` 解析到 `::1` 导致重复拉起后端）；仿真器配置页新增「🔗 连接已有仿真器」 |

### 真机联调时修掉的问题（2026-09 实测）

| 问题 | 原因 | 处理 |
| --- | --- | --- |
| 点「暂停」后再点「降落」报 500、无人机卡在空中 | 暂停会 `enableApiControl(False)`，后端没重新接管就直接发降落指令 | 降落前重新接管；高度收敛失败也不阻断 `landAsync` |
| 巡航会无故退出（`manual_override`） | 人工接管检测用的是**全局键盘状态**，在别的窗口打字（w/a/s/d/空格）也会命中 | 限定为**只有 CarlaAir 窗口在前台时**才判定 |
| 暂停后就地降落 → 再点开始巡航起不来 | 无人机停在航线中段，首航点距它 200m 被拒 | 自动**从最近的航点接着飞**（终点≈起点，下一轮可从头开始） |
| 界面上报「后端启动失败」且出现两个后端抢 5000 端口 | Electron 用 `localhost` 握手，Windows 可能先解析到 `::1` 而后端只监听 IPv4 | 握手改用 `127.0.0.1` + 超时 3s，现在稳定复用同一个后端 |
| 后端后起来连不上已在运行的仿真器 | 没有"只连接不重启"的入口 | 新增 `/api/carla/connect` 接口 + 界面按钮 + **后端自动附着视线程** |

## 5. 已知限制（如实记录）

- 规划/保存需要 CARLA 仿真器运行（**预览不需要**）
- 自定义航线的 `route_id` 每次保存都会更新；重启应用后模式回到"固定航线"（历史自定义航线文件仍保留在 `recordings/drone_routes/custom/`）
- 已保存的历史自定义航线暂时没有"重新载入编辑/删除"的入口，只能重新点一条
- 吸附精度取决于 CARLA 道路拓扑的疏密：锚点用的是 CARLA 投影后的路面位置（精确到车道中心线），
  接入图的那条边仍是拓扑折线；路线主体沿的是拓扑图上的边
- 地图视图缩放/平移是本页临时状态，切页或重新"读取地图"会回到自适应视图

## 6. 分享给队友 / 上传到 git

仓库里已经放了 `.gitignore`，会自动排除 **`node_modules/`（约 430MB）**、`.venv/`、`__pycache__/`、`datasets/`。

**要提交**：所有源码 + `recordings/`（约 3MB）。`recordings/` 里是各张地图的道路拓扑缓存和已标定的固定巡航航线，**少了它队友不启动 Carla-Air 就看不到"地图与路线"页的预览**，所以千万别忽略。

队友 clone 下来只需要：装好 Node.js（和 Python+flask，或直接让他有 Carla-Air 环境）→ 双击 `启动平台.bat`。缺的前端依赖脚本会自己装。

> ⚠️ 如果之后要改 `启动平台.bat`，请用编辑器"另存为 **UTF-8 带 BOM**、换行 **CRLF**"。cmd 对批处理的编码和换行很敏感：UTF-8 不带 BOM 中文会乱码，LF 换行会让脚本语法错乱。
