# Drone Dataset Platform · 用户使用指南

欢迎使用无人机数据集生成平台！本工具基于 CARLA-Air 仿真器，帮助你快速生成带有多传感器标注的无人机数据集，用于感知算法训练。

> **想直接跑起来？** 在项目根目录双击 **`启动平台.bat`** 即可（自动装依赖、自动找 Python、自动起后端和界面）。
> 详细说明见 [`README_启动说明.md`](README_启动说明.md)。

---

## 📥 获取 Carla-Air 底层架构（首次使用前）

本平台依赖 **Carla-Air** 仿真环境作为底层数据生成引擎。首次使用前，请按以下步骤获取并准备 Carla-Air 文件：

### 1. 下载 Carla-Air 压缩包
- 从项目官方仓库或指定网盘下载windows版的预编译压缩包，（请确保磁盘有至少 **30 GB** 可用空间）。

### 2. 解压到目标目录
- 将压缩包解压。 解压后，目录结构应类似如下：
  ```
  Carla-Air/
  ├── WindowsNoEditor/          
  ├── StartCarlaAir.bat         ← 启动脚本（平台需要此文件）
  ├── StopCarlaAir.bat
  ├── TestEnv.bat
  ├── SetupEnv.bat
  ├── AirSimConfig/
  │   └── settings.json         ← 平台需要此文件路径
  ├── PythonAPI/                ← CARLA Python API
  ├── auto_traffic.py
  ├── CarlaAir.ps1
  ├── trajectories/             
  └── ...（其他文件和文件夹）
  ```

### 3. 环境设置
- 如果电脑环境中没有conda，请先下载并安装一个 Anaconda 或者 Miniconda，以确保后续环境配置正常
- 接着，请运行目录中的 `SetupEnv.bat` 确保过程中无异常情况。
- 运行 `TestEnv.bat` 确保测试项都显示pass (测试时CarlaAir未启动会报一个warn提示端口2000没有监听到信息，该警告可忽略。)
- 在对应环境下安装 `Flask 3.1.3` 和 `flask-cors 6.0.2`

完成上述准备后，即可继续按照下一节“平台首次使用（必做）”进行路径配置。

## 📦 平台首次使用（必做）

### 1. 配置 Carla-Air 路径
- 打开软件，点击左侧导航栏 **“🚀 仿真器配置”**
- 在 **“手动配置”** 区域填写：
  - **Carla-Air 文件夹路径**：选择包含 `StartCarlaAir.bat` 的文件夹（例如 `D:\Drone-Dataset-Platform\Carla-Air`）
  - **Python 解释器路径**：选择你安装了 CARLA API 的 Python 环境（例如 `D:\miniconda3\envs\carlaAir\python.exe`）
  - **Airsim settings路径**：在你安装的 CarlaAir 的 airsimconfig 文件夹里（例如 `"D:\Drone-Dataset-Platform\Carla-Air\AirSimConfig\settings.json"`）
- 点击 **“保存配置”**，然后关闭软件重新启动（配置才会生效）

> 💡 如果你不清楚 Python 解释器路径，可以打开 Anaconda Prompt 输入 `where python` 查看路径。

### 2. 设置数据集保存位置
- 点击左侧 **“📦 数据资产”**
- 点击 **“选择文件夹”**，指定一个空文件夹用于存放采集的数据集（默认是 `./datasets/`）

## 🚁 基本工作流（每次采集）

### 第一步：启动 Carla-Air
- 进入 **“🚀 仿真器配置”** 页面
- 点击 **“🚀 启动 CARLA-Air”**，等待约 20～60 秒，直到状态变为 **“✅ Carla-Air 运行中”**
- 如果启动失败，检查上方路径配置是否正确

### 第二步：选择地图 (注意！以下所有参数设置只有在点击生成数据集后生效)
- 进入 **“📡 采集控制”** 页面
- 从 **“🗺️ 启动地图”** 下拉框选择地图（例如 `Town10HD`）

### 第三步：配置传感器
- 在 **“📡 无人机传感器套件”** 区域，点击任意传感器卡片右上角的开关，启用/禁用
- 点击卡片上的 **▼** 可展开，微调传感器的位置、旋转角度或专属参数（分辨率、FOV 等）
- 如果不想用 AirSim 传感器（红外、场景相机等），保持关闭即可
- 毫米波雷达和动态视觉传感器暂时没有数据返回，请不要启用。

### 第四步：设置天气
- 进入 **“🌤️ 天气配置”** 页面
- **官方预设模式**：点击卡片选择天气（晴朗、多云、日落、雨等），预览区会更新图标
- **专家模式**：点击 **“自主参数调控”**，拖动滑块调整云量、降雨、风力、雾浓度等

### 第五步：自动巡航
- 在 **“路线规划”** 页面，设置 **“高度”** 或 **“速度”**

### 第六步：设置采集参数
- **采集时长**：1～300 秒（例如 30 秒）
- **采样帧率**：1～60 FPS（例如 10 FPS）
- 总帧数会自动计算，显示在下方

### 第七步：生成数据集
- 点击 **“🚁 生成数据集”** 按钮（或按键盘 `Ctrl + G`）
- 等待进度条走完，期间不要关闭软件或停止 Carla-Air
- 生成成功后，通知栏会提示 **“数据集生成成功！共 X 帧数据”**

### 第八步：查看数据集
- 点击左侧 **“📦 数据资产”**，可以看到所有生成记录
- 点击任意记录可查看详细信息
- 数据集文件保存在你之前设定的文件夹中（按传感器类型分文件夹存放）

## ✈️ 无人机自动巡航（高级功能）

如果你想让无人机自动沿道路飞行，可以使用自动巡航功能。

### 使用方法
1. **启动 Carla-Air**（按基本工作流第一步）
2. 进入 **“🗺️ 路线规划”** 页面
3. 设置 **巡航高度**（默认 45 米）和 **巡航速度**（默认 8 m/s）
4. 点击 **“✈️ 开始自动巡航”**，系统会自动：
   - 连接 AirSim 并起飞
   - 根据当前地图生成道路巡航路线
   - 沿道路自动飞行
5. 实时状态会显示在右侧面板（位置、路径进度）
6. 点击 **“⏸️ 暂停”** 可停止巡航（无人机悬停）
7. 点击 **“🛬 降落”** 可使无人机平稳着陆

> 💡 切换地图时，系统会自动尝试重连无人机并恢复飞行（如果之前已起飞）

## ❓ 常见问题快速解决

| 问题 | 解决方法 |
| :--- | :--- |
| **启动 Carla-Air 一直超时** | 检查 Carla-Air 路径是否正确；关闭杀毒软件或防火墙；确保没有其他程序占用端口 2000 |
| **传感器数据没有保存** | 检查数据集保存路径是否有效且有写入权限；查看后端控制台是否有报错 |
| **生成帧数比预期多很多** | 这是一个已知问题，临时方案：生成完成后手动点击 **“停止传感器”**（后端会自动销毁），或重启 Carla-Air |
| **AirSim 传感器（红外/场景相机）采集失败** | 当前版本下，AirSim 传感器在同步模式下会超时。如果你需要使用 AirSim 传感器，请暂时只启用 CARLA 传感器，或联系开发者获取修复版本 |
| **地图切换后无人机无法连接** | 在地图切换完成后，手动点击“路线规划”页面的 **“开始自动巡航”**，系统会自动重连 |
| **应用启动后报错“未找到 Carla-Air 路径”** | 重新进入“仿真器配置”页面，填写路径并保存，然后重启应用 |
| **想要清空历史数据集记录** | 在“数据资产”页面点击 **“清空”** 按钮 |
